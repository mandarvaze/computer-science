# 🐍 Python Exam Study Hub (8th Grade CS)

Welcome! This repository contains hands-on Python scripts designed to help you prepare for the computer science exam. Every file is fully commented so you can read, run, and learn directly from the code.

---

## 📂 Code Directory & Topics

Use the links below to jump straight to the code files for each topic:

| File / Topic | Description & Contents | Exam Focus Areas |
| :--- | :--- | :--- |
| 📄 [`01_basics_and_io.py`](./01_basics_and_io.py) | Covers printing, variable assignment, basic data types, and taking user inputs. | `print()`, `input()`, type casting (`int()`, `float()`) |
| 📄 [`02_operators.py`](./02_operators.py) | Arithmetic, comparison, and logical operators with step-by-step output tracking. | Floor division `//`, Modulus `%`, `and`/`or`/`not` |
| 📄 [`03_control_flow.py`](./03_control_flow.py) | Conditional logic and decision-making structures. | `if`, `elif`, `else` blocks & proper indentation |
| 📄 [`04_loops.py`](./04_loops.py) | Iteration examples including counts, accumulators, and break/continue statements. | `for` loops, `while` loops, `range(start, stop, step)` |
| 📄 [`05_functions.py`](./05_functions.py) | Reusable code blocks, parameter passing, and return values. | `def` keyword, arguments, `return` vs `print()` |
| 📄 [`06_lists.py`](./06_lists.py) | Compound data structures, element indexing, mutation, and dictionaries. | Lists, slicing, methods (`append()`, `pop()`), and key-value dicts |
| 📄 [`07_practice_questions.py`](./07_practice_questions.py) | Solved exam-style coding questions and output tracing problems. | Problem-solving & common exam code snippets |

**Note:** A lot of the print statements have "/n"("---" is just decorational), it means a new line(basically will skip a line and then print the statement after it.)

## 🛠️ How to Study with These Files

1. **Read the Comments:** Each file contains detailed inline comments explaining *why* the code works the way it does.
2. **Run the Code:** Run the scripts in your Python environment or IDE to test different inputs and see the output in real time.
3. **Modify & Experiment:** Change values, add print statements, or break things on purpose to see how Python handles errors!
